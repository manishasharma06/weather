# Aviation Weather App

A Java-based command-line application that fetches and displays real-time **aviation weather data (METAR/TAF)** for airports around the world using their ICAO codes.

This project is a great example of working with **Java APIs, JSON parsing**, and implementing a real-world utility focused on aviation and weather forecasting.

---

## Features

- Fetches real-time **METAR** (Meteorological Aerodrome Report) and **TAF** (Terminal Aerodrome Forecast) data.
- Parses and displays weather info in a human-readable format.
- Connects to **AVWX REST API** for reliable aviation weather data.
- Simple CLI interface for input/output.
- Includes unit tests for major classes and methods.

---

## Tech Stack

- **Java 8+**
- **Maven** – for dependency and build management
- **Gson** – for JSON parsing
- **JUnit** – for unit testing
- **AVWX API** – for live weather data
